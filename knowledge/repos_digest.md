## Licence / usage warnings — summary

- **Moirai / uni2ts: NON-COMMERCIAL.** Do not deploy. Listed here only so nobody adds it later by mistake.
- **ProsusAI/finbert weights: CC BY-NC-SA 4.0 (non-commercial).** OK for this paper-only research bot.
- **TimesFM 3.0 weights: non-commercial for self-hosted use** (code + ≤2.5 weights are Apache-2.0).
- **vectorbt: PHASE 2.** Not installed, not used, until the backtest phase is explicitly started.
- **Chronos (Apache-2.0) and TimesFM ≤2.5 (Apache-2.0):** permissible as optional ensemble/backup forecasters only — Kronos stays primary because it is finance-specific.
- **Kronos MIT, TradingAgents Apache-2.0, Qlib MIT, pandas-ta-classic MIT:** no licence blocker for this bot (verified above).
